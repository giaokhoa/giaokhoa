# AGENTS.md — Oxlint Config

Chỉ chứa các preset dùng chung Oxlint của TypeScript 7. Giữ ranh giới package: package tự chọn \`base.json\` và \`react.json\`. Không đưa đường dẫn app/package cụ thể vào preset chung. Các rule quan trọng phải ở mức error. Không đưa suppression cũ vào cấu hình mới; sửa code trước khi yêu cầu lint xanh. Không viết comment trong code hay cấu hình; tài liệu viết bằng tiếng Việt.
